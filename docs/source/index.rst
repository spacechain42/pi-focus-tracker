The ``pi-focus-tracker`` project is a Python pomodoro timer designed for the Raspberry Pi.
In addition to core timer function and lcd display, it will eventually support focus quality tracking and integration with
a phone app with analytics on optimal focus times and durations.

Project source code is hosted on `GitHub <https://github.com/spacechain42/pi-focus-tracker>`_.
